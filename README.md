### 10.11.2026 / Версия 0.3 - Базовый CRUD и пользователи

- В настоящий момент система предоставляет базовый функционал: регистрация/вход, оформление и обработку заказов, управление аптеками, остатками, аккаунтами работников (они регистрируются менеджером);
- Обработка действий пользователя проверена путем взаимодействия с интерфейсом веб-платформы.

### ЗАПУСК
- Если на машине используется СУБД PostgreSQL:
  - Изменить поле `DefaultConnection` файле `appsettings.json`: ввести название локальной БД, имя пользователя и пароль;
  - Провести миграцию:
    - В папке проекта запустить Powershell;
    - Восстановить зависимости: `dotnet restore`;
    - Выполнить команду `dotnet ef Update-Database`;
    - Добавить тестового менеджера при помощи `dotnet run --project TP_pharmacy --initialize-database`;
    - Запустить проект при помощи `dotnet run --project TP_pharmacy`;
    - Перейти на `https://localhost:5000`.
- Если на машине используется иная СУБД:
  - Аналогично алгоритму выше, за исключением строки соединения; её необходимо ввести заново в соответствии с используемой СУБД.
