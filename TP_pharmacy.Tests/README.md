# Основные NUnit-тесты аптечной системы

В `OrderServiceTests.cs` оставлены 13 сценариев (12 методов, один из них имеет два `TestCase`). Тест-заглушка `UnitTest1.cs` удалён.

## Проверяемые функции

1. CRUD товара: создание, чтение, изменение названия/цены, удаление.
2. Оформление заказа: сумма, позиции, резервирование, списание остатков, очистка корзины.
3. Запрет оформления пустой корзины.
4. Откат заказа при недостатке товара: остатки и корзина не изменяются.
5. Списание бонусов: итоговая сумма, баланс и журнал операций.
6. Запрет списания более 50% стоимости.
7. Запрет списания сверх бонусного баланса.
8. Отмена заказа: возврат партий и бонусов, запрет повторного возврата.
9. Полный цикл статусов Pending → Processing → Ready → Completed и дата завершения.
10. Запрет пропуска статусов.
11. Обычная продажа: покупка, сумма, позиции и списание остатков.
12. Рецептурная продажа и запрет повторного использования рецепта.
13. Запрет продажи по просроченному рецепту.

## Запуск

Из каталога `TP_pharmacy`:

```powershell
dotnet test ./TP_pharmacy.Tests/TP_pharmacy.Tests.csproj --logger 'trx;LogFileName=postgresql-tests.trx'
```

Нужны SDK .NET 10, среда ASP.NET Core/.NET 9 и доступный PostgreSQL. Подключение настроено в `OrderServiceTests.cs`; роль должна иметь право создавать базы. Текущая локальная настройка содержит пароль в коде — не публикуйте её, для совместного использования рекомендуется переменная окружения.

Создаётся отдельная база `tp_pharmacy_tests_<GUID>`. Перед каждым тестом очищаются только её таблицы и заново добавляются исходные данные. После запуска база удаляется. База приложения не используется. При аварийном завершении процесса временная база может остаться.

Тесты интеграционные: выполняются реальные запросы и транзакции PostgreSQL. CRUD проверяется на уровне `PharmacyDbContext`, а бизнес-логика — через `OrderService`; обработчики страниц и HTTP-интерфейс не проверяются. Схема создаётся через `EnsureCreatedAsync`, поэтому миграции не проверяются. Конкурентные запросы и полный перебор граничных значений исключены из сокращённого набора.

TRX-отчёт: `TestResults/postgresql-tests.trx`.
